## 7. Residual risk and re-review conditions

- Developer-toolchain availability (§4.1/§4.2): a crafted image committed to the repository
  could hang `react-native bundle` on the build machine. Mitigated by code review of asset
  changes; no user or production impact. Re-review when `image-size` ships a fix.
- Latent DoS in a bundled-but-unreachable parser (§4.3): becomes real the moment deep linking
  is enabled. The guard is the absence of `linking`/universal links in `RootNavigator.tsx`
  and the Xcode project; any PR adding them must first re-run this review. Re-review when
  `@react-navigation/core` publishes a stable release depending on `query-string@>=9.4.0`.
- UNKNOWN: whether a hosted Supabase Edge runtime pulls any dependency outside `deno.lock`.
  INFERRED not: the `--frozen --lock` check (#8) passes over the entire `index.ts` import
  graph and the lock has no `jsr`/`remote` entries, so the deploy bundle resolves exactly
  the audited set.
- The advisory databases consulted are GitHub Advisory Database (via `npm audit`, `pnpm audit`,
  `gh api`) and Deno's audit service. A finding absent from both is out of this review's reach.
