## 8. Acceptance (H04-01-AC1 — "audits executed and every advisory has a disposition")

### 8.1 What the manifest command's exit code means

The manifest command is `pnpm audit --json > …/pnpm.json; (cd apps/mobile && npm audit --json

> …/mobile.json)`. Run verbatim (§2 #3) it produces both reports and its shell status is **1**,
because `npm audit`'s exit code encodes _whether advisories exist_ (1 = at least one advisory
at or above `audit-level`), not whether the audit ran. It would be 0 only in a tree with zero
advisories — i.e. only if the three accepted-risk advisories in §4 were removed, which §6
shows cannot be done safely today. The package objective explicitly foresees this outcome
("document accepted risk otherwise"), so the criterion H04-01-AC1 grades is the sentence
"audits executed and every advisory has a disposition", and that is what §8.2 checks. The raw
exit code is recorded here and in the acceptance record's `note`; nothing in this review
changes `npm audit`'s arguments, `audit-level`, or exit status.

### 8.2 Criterion check (VERIFIED, §2 #16)

The manifest command verbatim, followed by a check that exits non-zero unless (a) both
reports are well-formed audit output (`metadata.vulnerabilities` present, no `error` object,
so the audits did execute), (b) every GHSA id in either report has a `### … GHSA-…` heading
in this document whose `Disposition` row is `UPGRADED`, `ACCEPTED RISK`, or `NOT APPLICABLE`,
and (c) every `Remediation floor` row in this document names a `pkg@version` that does **not**
satisfy `mobile.json`'s audited `vulnerabilities[pkg].range` (semver from
`apps/mobile/node_modules/semver`, already installed by `npm ci`). A new advisory appearing in
a future run fails this check until it is dispositioned, and a floor written inside the
vulnerable range (e.g. `query-string@9.4.0` against `5.0.0 - 9.4.1`) fails it as well.

```sh
pnpm audit --json > artifacts/advisories/pnpm.json; (cd apps/mobile && npm audit --json > ../../artifacts/advisories/mobile.json); node -e '
const fs = require("fs");
const out = [];
const log = (s) => { out.push(s); console.log(s); };
const finish = (code) => { fs.writeFileSync("artifacts/advisories/disposition-coverage.log", out.join("\n") + "\nexit " + code + "\n"); process.exit(code); };
const read = (f) => JSON.parse(fs.readFileSync(f, "utf8"));
const mobile = read("artifacts/advisories/mobile.json");
const pnpm = read("artifacts/advisories/pnpm.json");
const wellFormed = (r) => Boolean(r && !r.error && r.metadata && r.metadata.vulnerabilities);
if (!wellFormed(mobile) || !wellFormed(pnpm)) { log("audit report malformed (audit did not execute)"); finish(1); }
const ids = new Set();
for (const v of Object.values(mobile.vulnerabilities)) for (const via of v.via) if (via && via.url) { const m = via.url.match(/GHSA-[0-9a-z]{4}-[0-9a-z]{4}-[0-9a-z]{4}/); if (m) ids.add(m[0]); }
for (const a of Object.values(pnpm.advisories || {})) if (a.github_advisory_id) ids.add(a.github_advisory_id);
const doc = fs.readFileSync("docs/security/ADVISORIES_2026-09-08.md", "utf8");
let missing = 0;
for (const id of [...ids].sort()) {
  const re = new RegExp("^### [0-9.]+ " + id + "[^\\n]*\\n(?:(?!\\n### )[\\s\\S])*?\\| Disposition[^\\n]*\\*\\*(UPGRADED|ACCEPTED RISK|NOT APPLICABLE)\\*\\*", "m");
  const hit = re.test(doc);
  log(id + ": " + (hit ? "dispositioned" : "MISSING disposition"));
  if (!hit) missing++;
}
const semver = require("./apps/mobile/node_modules/semver");
let badFloors = 0;
const floorRe = /^\| Remediation floor +\| `([^`@\s]+(?:\/[^`@\s]+)?)@(\d+\.\d+\.\d+)`/gm;
for (const m of doc.matchAll(floorRe)) {
  const [, pkg, ver] = m;
  const v = mobile.vulnerabilities[pkg];
  const range = v && v.range;
  const inside = range ? semver.satisfies(ver, range) : false;
  log("floor " + pkg + "@" + ver + " vs audited range " + JSON.stringify(range) + ": " + (range ? (inside ? "INSIDE vulnerable range" : "outside vulnerable range") : "package not in audit report"));
  if (!range || inside) badFloors++;
}
log("mobile: " + JSON.stringify(mobile.metadata.vulnerabilities) + " pnpm: " + JSON.stringify(pnpm.metadata.vulnerabilities));
log("advisories=" + ids.size + " missing=" + missing + " floors=" + [...doc.matchAll(floorRe)].length + " badFloors=" + badFloors);
finish(missing || badFloors ? 1 : 0);
'
```
